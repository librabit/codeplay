## 세트는 각 아이템 가격의 합 * 0.8

```
class burger():
    def __init__(self):
        pass

class specialBurger(burger):
    def __init__(self):
        pass
```
1. 주문을 받는다
2. 받은 주문을 인스턴스로 생성한다
3. 받은 주문이 언제 나올 지 알려주는 메시지를 보여준다.
4. 음식이 나간다
5. 매출에 판매한 음식이 기록된다.
6. 하루 장사가 끝나면 매출이 얼마인지 보여준다.
